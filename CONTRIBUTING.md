# Участие в разработке

Спасибо, что хотите внести вклад!

## Вкладываться легко

1. Fork → ветка `feat/что-нибудь` или `fix/что-нибудь`.
2. Установите зависимости для разработки:

   ```bash
   python3 -m venv .venv && source .venv/bin/activate
   pip install -r requirements-dev.txt
   ```

3. Сделайте изменения и покройте их тестами.
4. Проверьте локально:

   ```bash
   ruff check .
   ruff format --check .
   pytest
   ```

5. Откройте pull request по шаблону.

CI прогоняет те же команды — красный `ruff` или `pytest` заблокирует слияние.

## Соглашения

- **Язык** — русский: код, сообщения бота, docstring, комментарии, тексты в README.
- **Стиль** — форматирует `ruff format`, линтит `ruff check`. Не отключайте правила без причины.
- **Логика вне Telegram** — всё, что не требует сети (`triggers.py`, `storage.py`, `config.py`), остаётся чистыми функциями с тестами.
- **Секреты** — `.env` в `.gitignore`. Токенов и `file_id` в коммитах быть не должно.
- **Коммиты** — [Conventional Commits](https://www.conventionalcommits.org/): `feat:`, `fix:`, `docs:`, `test:`, `chore:`.
- **Заголовок PR** — одна строка: что изменилось и зачем.
