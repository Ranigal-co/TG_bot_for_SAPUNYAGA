# media/

Сюда положите запасной кружок с именем **`video_note.mp4`**.

Если кружок не задан пересылкой или командой `/setnote`, бот при первом ответе
залит этот файл в Telegram, сохранит полученный `file_id` в `data/note.json`
и дальше будет использовать его.

Файл не попадает в git (см. `.gitignore`) — каждый разработчик кладёт свой
локально.

Требования к файлу: кружок, то есть видео **640×640**, длительность до 60 секунд,
формат `.mp4`, размер до 10 МБ (лимиты Telegram).
